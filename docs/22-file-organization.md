# Struktur source Valora

Perapihan 4 Oktober 2026 mengelompokkan source berdasarkan fitur tanpa perubahan UI, route, wire contract, schema database, atau identitas controller OpenAPI.

## Aturan

- File dan folder source memakai bahasa Inggris dan kebab-case. Folder menyediakan konteks fitur; basename menyebut peran.
- Web: src/app untuk routing; src/features untuk auth/account/items/assessments/market/listings/offers/conversations/transactions/corrections/passport/impact/profile/admin; components/layout untuk shell/header/footer; components/ui untuk kontrol bersama; hooks dan lib untuk logika lintas fitur; styles untuk CSS.
- API: main.ts, app.module.ts dan seed.ts tetap entrypoint. modules memuat fitur dengan controller/service terpisah. shared memuat HTTP, transaksi lintas fitur, pagination, konteks request dan pemulihan tindakan. infrastructure memuat konfigurasi, database, storage, email dan jobs. history menggabungkan layanan proyeksi Passport/Impact dan ledger.
- Contracts dipisahkan per domain dan diimpor publik melalui @valora/contracts. index.ts secara eksplisit mengekspor hanya 132 nama publik semula.
- scripts/smoke, scripts/demo, scripts/database dan scripts/helpers memisahkan tujuan skrip. Test browser berada di tests/e2e. Nama perintah package dan lokasi fixture .local dipertahankan.
- Perpindahan CSS mempertahankan byte dan urutan import. Nama migrasi, generated Prisma, data lokal, aset dan bukti historis dipertahankan.

| E2E desktop dan mobile | 25/26 skenario lolos setelah pengujian ulang selector publik; matriks akses seluruh 47 halaman lolos pada kedua viewport |

Pengujian browser pertama menghasilkan 23 skenario lolos dan 3 gagal. Dua kegagalan publik berasal dari selector lama untuk dropdown kategori dan `.market-grid`. Ekspektasi diganti sesuai UI yang telah tersedia—tombol kategori dan `.catalog-grid`—kemudian kedua pengujian ulang lolos. Test sesi juga diselaraskan dengan shell akun dan jumlah 47 halaman.

Satu kegagalan yang masih terdeteksi adalah overflow horizontal pada `/app/admin/koreksi/[id]` ketika bukti dan form tindakan tersedia: lebar dokumen 430px pada viewport 390px. Pengujian ulang mengonfirmasi kegagalan yang sama. Isi komponen koreksi dan seluruh CSS identik dengan backup sebelum perapihan, sehingga temuan layout ini tidak berasal dari perubahan isi source pada pekerjaan ini. Perbaikan UI admin menjadi pekerjaan lanjutan; assertion overflow tetap aktif.

Baseline, backup source, manifest, hasil perbandingan, screenshot/trace diagnostik admin mobile, dan artefak build web berada di `.local/file-cleanup`. Output kompilasi API yang mengacu pada file lama sudah dibersihkan. Migrasi, source Prisma generated, aset, data/credential lokal, dan bukti review historis tidak dipindahkan.
