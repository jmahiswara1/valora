# Passport QR Valora

Extend the existing white/forest/cream world with a centered native dialog.
The scannable square is the focus: forest modules on opaque white, four-module
quiet zone, no logo overlay or decorative pattern. Show Item ID rather than
private owner details. Keep title and close control clear; use one soft sage
access explanation and pill actions with 44 px targets.

Entry points: current owner item detail, owner Passport, accessible public
Passport. A saved QR encodes only the canonical public URL. Draft and hidden
owner views explain unavailable public access; LIMITED explains the status
page. Sharing never changes publication eligibility or moderation.

Desktop dialog max width 500 px, padding 28 px, radius 20 px; phone padding
20 px with stacked actions. QR display max 256 px (phone 224 px); PNG 1024 px.
Respect viewport height, internal scrolling, Escape, focus containment/return,
account isolation, visible retry, manual copy fallback, and local URL messaging.

Acceptance: readable at 320/390/430/768/1440 px, decoded PNG matches the exact
public URL, public/private projections remain separate, no external QR service.
