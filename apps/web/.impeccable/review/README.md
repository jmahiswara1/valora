# Arsip review desain

Direktori ini menyimpan laporan review historis, hasil inspeksi JSON, dan skrip
fixture sintetis. Catatan tersebut menggambarkan kondisi saat review dilakukan;
path source atau temuan lama dapat berbeda dari implementasi terbaru.

Screenshot PNG tetap disimpan lokal dan diabaikan Git. Tautan atau nama
screenshot dalam laporan historis merujuk ke arsip lokal tersebut, sehingga
gambar tidak tersedia dari clone GitHub. Catatan historis dipertahankan tanpa
mengubah hasil review sebelumnya.

Gambar yang digunakan aplikasi berada di `public/images` dan tetap masuk Git.
